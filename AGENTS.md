# Rogue Quant Project Rules

This repository follows the standard Rogue Quant project rules. All contributors and automated agents must adhere to the following guidelines:

## Requirements

* **Python Version**: Python 3.11 or higher is required.
* **Core Libraries**: Use `hmmlearn` and `hyperliquid-sdk` for core functionalities.
* **Architecture**: Follow class-based architectures for consistency and maintainability.
* **Test Coverage**: A minimum of 80% test coverage is strictly required.
* **Safety First**: A deterministic kill-switch priority must be implemented and maintained across all active trading modules.
